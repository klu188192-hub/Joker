## 🏗️ Agent #1 个人炒股 AI 助手 · 4 大功能

### F1 · 自然语言选股 + 习惯排序 (续费命脉)

```
用户主动问 → AI 按习惯筛选排序 → 用户决策

用户: "找今天涨幅 5% 以下的医药股"
   ↓
DeepSeek 解析条件 (板块/涨幅/资金/技术)
   ↓
akshare 筛 (100 → 50)
   ↓
基于用户行为画像排序 (50 → 5)
   ↓
输出 5 只, 每只附:
  • 为什么推 (匹配条件 + 习惯)
  • 你历史买类似票的胜率
   ↓
用户决定 (准确度责任在用户, 不在 AI)

合规话术: "您已自行选择条件, AI 仅辅助筛选, 不构成投资建议"
```

### F2 · 交易复盘 + 行为画像 (续费命脉)

```
用户上传交易记录 (csv / 截图) → AI 行为画像 → 周报 / 月报 PDF

输出:
  • alpha 风格 (成长小盘 / 大盘核心 / etc)
  • 90 天行为基准
  • 当周 / 当月偏离度
  • 历史犯错模式 (追涨/恐慌/集中度过高)
  • 强项 (北向跟随胜率 / 财报前减仓纪律)
  • 下周 3 个建议
```

**复用乔克交易社 v3.1 季度个人体检模板**, 改造为周报 / 月报

### F3 · 个股深度分析

```
用户输入代码 → 5 秒出结构化报告

输出:
  • 基本面 (财报 / 估值 / 北向)
  • 技术面 (均线 / MACD / 支撑压力)
  • 个性化提示 (基于用户历史买该股记录)
  • 风格匹配度评分
```

### F4 · 实时警报推送

```
用户设条件 → 系统每 30 秒检测 → 触发推送

支持:
  • 价格突破/跌破
  • 资金异常
  • 财报发布前提醒
  • 用户自定义触发条件

推送通道: 微信 (wxpusher) + 企微 webhook
延迟: 实时 15-30 秒 + 推送 5 秒 = 用户感知 30-40 秒
```

## 🎯 续费率护城河 (这是 SaaS 的真核心)

| 时间维度 | 用户依赖 |
|---|---|
| 第 1 周 | F3 新鲜感 |
| 第 1 月 | F4 警报 + F1 选股开始有用 (20+ 次交易后画像建立) |
| 第 3 月 | F2 周报, 用户看到成长曲线 |
| 第 6 月 | 100+ 次交易档案, "比用户自己更懂他" |
| 第 12 月 | 退订 = 失去 1 年累计档案, 切换成本极高 |

**护城河不是技术, 是用户数据沉淀**

## 📅 Phase 2 · Agent #1 业务 (W5-8)

### W5 · F3 个股深度分析

**为什么先做 F3**: 最简单, 验证整链路 (LLM + 数据源 + UI)

**实现**:
- prompt 模板 (复用现有 daily_review prompt)
- 输入: 股票代码
- 数据源: Tushare 基本面 + akshare 龙虎榜 + Tushare 技术指标
- LLM: DeepSeek Reasoner (推理)
- 输出: Markdown 报告 + plotly K 线图

**验收**: 输入 "002594" → 5 秒内出报告 + K 线图

### W6 · F4 警报推送

**实现**:
- alerts 表 + CRUD API
- APScheduler 每 30 秒检查
- 触发条件解析 (价格突破 / 跌破 / 自定义)
- 触发 → 调推送服务
- 警报历史查询

**验收**: 设警报 "茅台跌破 1620" → 满足时手机 30-40 秒内收到通知

### W7 · F2 交易复盘

**实现**:
- 上传 csv 接口
- 交易记录解析 (通用券商 csv 格式)
- 行为画像 prompt (复用乔克交易社 v3.1 框架)
- alpha 风格识别
- 周报 / 月报 PDF 生成 (WeasyPrint)

**验收**: 上传 1 个月交易记录 → 30 秒出周报 PDF

### W8 · F1 自然语言选股

**重点**: 续费命脉, 必须做好

**实现**:
- DeepSeek 解析自然语言条件
- akshare 筛选
- 基于 F2 行为画像排序
- 输出: 5 只 + 每只解释

**验收**: 用户问 "找今天涨幅 5% 以下的医药股", 30 秒出 5 只 (匹配度排序)

**Phase 2 总验收**: Agent #1 完整可用, 你自己跑通 6 大场景剧本

## 📅 Phase 3 · 上架 + UI 美化 (W9-12)

### W9 · UI 美化

**重点**:
- streamlit-shadcn-ui 集成
- 自定义 CSS (字体 / 配色 / 卡片)
- 暗色 / 亮色主题
- 移动端响应式 (虽然桌面应用, 也要好看)

**验收**: 截图给 5 个朋友看, 都说"挺漂亮"

### W10 · 小程序商城

**重点**:
- 小程序基础页面 (首页 / 详情 / 我的)
- 微信支付集成
- 授权码生成 + 短信发送
- 续费流程

**验收**: 测试账号能完整跑通 "浏览 → 支付 → 收码 → 下载"

### W11 · 提交审核 + 内测

**重点**:
- 小程序提交审核 (走"工具"类目, 不带金融字样)
- 内测 5 朋友 (跑完整流程)
- bug 修复

**类目策略**:
- 小程序名: "乔克 AI 工具箱"
- 描述: "数据分析助手, 帮您整理交易记录"
- 不出现: "投资" / "金融" / "证券" / "股票分析"

**验收**: 内测 5 朋友 0 阻断 bug

### W12 · 灰度发布

**重点**:
- 灰度发布给 10-20 人
- 微信群客服 (wechat_bot 自动 + Joker 兜底)
- 第 1 批付费数据收集
- 续费率初步观察

**验收**: 10+ 付费用户, 跟踪 30 天续费数据

## ⚠️ 关键风险节点 + 应对

| 风险节点 | 影响 | 应对 |
|---|---|---|
| W4 PyInstaller 杀毒 | 客户装不上 | 立刻买代码签名证书 |
| W11 小程序审核被拒 | 线上路径阻塞 | 启动线下卖 (个人微信收款) |
| W12 续费率 < 30% | 商业模式不成立 | 立刻复盘 + 调产品 |
| W13 单 agent 边际 | 用户买单卡不全包 | 改套餐结构, 强推全包 |

## 🗂️ 全表清单 (15 张, 按业务分组)

### 用户与权限
- `users` 用户主表
- `auth_codes` 授权码
- `devices` 设备指纹绑定
- `sessions` JWT 会话 (用于强制下线)

### 商品与订阅
- `agents` Agent 商品定义
- `plans` 套餐定义 (体验装/单卡/全包/年卡)
- `user_plans` 用户订阅 (含 expires_at)
- `user_agents` 用户拥有的 agent (从 user_plans 派生)

### 计费与日志
- `quota_usage` 配额使用 (月度统计)
- `llm_calls` LLM 调用日志 (计费 + 审计)
- `payments` 支付订单

### Agent #1 业务数据
- `trade_records` 用户上传的交易记录
- `behavior_profile` 用户行为画像 (F1/F2 核心)
- `alerts` 警报配置
- `alert_history` 警报触发历史
- `reports` 生成的 PDF 报告

### 推送与运营
- `push_logs` 推送历史

## 📊 完整 Schema (PostgreSQL 15)

```sql
-- ========================================
-- 1. 用户与权限
-- ========================================

CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    openid VARCHAR(64) UNIQUE,           -- 微信 OpenID (商城登录)
    nickname VARCHAR(64),
    phone VARCHAR(20),
    avatar_url TEXT,
    status SMALLINT DEFAULT 1,           -- 1=正常 / 0=冻结 / -1=黑名单
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    last_login_at TIMESTAMPTZ
);
CREATE INDEX idx_users_openid ON users(openid);
CREATE INDEX idx_users_status ON users(status);

-- 授权码: 客户付款后生成, 用于桌面应用激活
CREATE TABLE auth_codes (
    id BIGSERIAL PRIMARY KEY,
    code VARCHAR(16) UNIQUE NOT NULL,    -- 12 位, 排除 0/O/I/l
    user_id BIGINT REFERENCES users(id),
    plan_id BIGINT REFERENCES plans(id),
    payment_id BIGINT REFERENCES payments(id),
    issued_at TIMESTAMPTZ DEFAULT NOW(),
    activated_at TIMESTAMPTZ,            -- 首次激活时间
    expires_at TIMESTAMPTZ NOT NULL,     -- 到期时间 (续费时改这个)
    status SMALLINT DEFAULT 1,           -- 1=待激活 / 2=已激活 / 0=过期 / -1=作废
    notes TEXT
);
CREATE INDEX idx_auth_codes_user ON auth_codes(user_id);
CREATE INDEX idx_auth_codes_code ON auth_codes(code);
CREATE INDEX idx_auth_codes_expires ON auth_codes(expires_at);

-- 设备指纹: 一码一机
CREATE TABLE devices (
    id BIGSERIAL PRIMARY KEY,
    auth_code_id BIGINT REFERENCES auth_codes(id),
    user_id BIGINT REFERENCES users(id),
    fingerprint VARCHAR(64) NOT NULL,    -- MAC + CPU hash
    os VARCHAR(32),                       -- Windows10 / macOS14
    app_version VARCHAR(16),              -- 1.0.0
    first_seen_at TIMESTAMPTZ DEFAULT NOW(),
    last_seen_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(auth_code_id, fingerprint)
);
CREATE INDEX idx_devices_user ON devices(user_id);

-- JWT 会话: 用于强制下线 / token 失效
CREATE TABLE sessions (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    device_id BIGINT REFERENCES devices(id),
    jwt_jti VARCHAR(64) UNIQUE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    expires_at TIMESTAMPTZ NOT NULL,
    revoked_at TIMESTAMPTZ
);
CREATE INDEX idx_sessions_jti ON sessions(jwt_jti);

-- ========================================
-- 2. 商品与订阅
-- ========================================

CREATE TABLE agents (
    id BIGSERIAL PRIMARY KEY,
    slug VARCHAR(32) UNIQUE NOT NULL,    -- stock_assistant / lhb_review / fr_audit
    name VARCHAR(64) NOT NULL,           -- "个人炒股 AI 助手"
    description TEXT,
    icon_url TEXT,
    cover_url TEXT,
    status SMALLINT DEFAULT 1,           -- 1=上架 / 0=下架
    sort_order INT DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE plans (
    id BIGSERIAL PRIMARY KEY,
    slug VARCHAR(32) UNIQUE NOT NULL,    -- trial / single / all_in_one / yearly
    name VARCHAR(64) NOT NULL,           -- "商城全包"
    price_cents INT NOT NULL,            -- 29900 = ¥299
    duration_days INT NOT NULL,          -- 30 / 365
    agent_ids JSONB,                     -- [] 表示全部 agent / [1,2] 表示指定
    quota_per_month INT,                 -- NULL=不限次
    description TEXT,
    sort_order INT DEFAULT 0,
    status SMALLINT DEFAULT 1
);

CREATE TABLE user_plans (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    plan_id BIGINT REFERENCES plans(id),
    auth_code_id BIGINT REFERENCES auth_codes(id),
    started_at TIMESTAMPTZ DEFAULT NOW(),
    expires_at TIMESTAMPTZ NOT NULL,
    status SMALLINT DEFAULT 1,           -- 1=有效 / 0=已过期 / -1=退款
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_user_plans_user ON user_plans(user_id);
CREATE INDEX idx_user_plans_expires ON user_plans(expires_at);

-- ========================================
-- 3. 计费与日志
-- ========================================

-- 月度配额使用 (Redis 主, DB 异步同步, 每天 1 次)
CREATE TABLE quota_usage (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    agent_id BIGINT REFERENCES agents(id),
    year_month CHAR(7) NOT NULL,         -- "2026-05"
    used_count INT DEFAULT 0,
    quota_limit INT,                     -- 当时套餐的限额 (snapshot)
    last_used_at TIMESTAMPTZ,
    UNIQUE(user_id, agent_id, year_month)
);

-- LLM 调用日志 (用于成本审计 + 异常检测)
CREATE TABLE llm_calls (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    agent_id BIGINT REFERENCES agents(id),
    action VARCHAR(64),                  -- screen / review / analyze / alert
    model VARCHAR(32),                   -- deepseek-chat / deepseek-reasoner
    input_tokens INT,
    output_tokens INT,
    cost_cents NUMERIC(10, 4),           -- 精确到 0.0001 分
    latency_ms INT,
    cache_hit BOOLEAN DEFAULT FALSE,
    error TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_llm_calls_user ON llm_calls(user_id);
CREATE INDEX idx_llm_calls_created ON llm_calls(created_at);

-- 支付订单
CREATE TABLE payments (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    plan_id BIGINT REFERENCES plans(id),
    amount_cents INT NOT NULL,
    wechat_order_id VARCHAR(64) UNIQUE,  -- 微信支付订单号
    out_trade_no VARCHAR(64) UNIQUE,     -- 自定义订单号
    status SMALLINT DEFAULT 0,           -- 0=待支付 / 1=已支付 / -1=退款 / -2=失败
    paid_at TIMESTAMPTZ,
    refunded_at TIMESTAMPTZ,
    raw_response JSONB,                  -- 微信回调原文
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_payments_user ON payments(user_id);
CREATE INDEX idx_payments_status ON payments(status);

-- ========================================
-- 4. Agent #1 业务数据
-- ========================================

-- 用户上传的交易记录 (F2 复盘 + F1 推荐基础)
CREATE TABLE trade_records (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    symbol VARCHAR(16) NOT NULL,         -- 002594 / sh600519
    name VARCHAR(64),                    -- 比亚迪
    action VARCHAR(8),                   -- buy / sell
    price NUMERIC(10, 3) NOT NULL,
    volume INT NOT NULL,                 -- 股数
    amount NUMERIC(14, 2),               -- 金额
    fee NUMERIC(10, 2),                  -- 手续费
    trade_at TIMESTAMPTZ NOT NULL,       -- 成交时间
    broker VARCHAR(32),                  -- 来源券商
    notes TEXT,
    raw_data JSONB,                      -- 原始 csv 行
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_trade_records_user_time ON trade_records(user_id, trade_at);
CREATE INDEX idx_trade_records_symbol ON trade_records(symbol);

-- 用户行为画像 (F1 推荐 + F2 复盘核心)
-- 每天凌晨重算一次
CREATE TABLE behavior_profile (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id) UNIQUE,
    
    -- 风格特征
    alpha_style VARCHAR(32),             -- "成长小盘" / "大盘核心" / "周期"
    risk_level SMALLINT,                 -- 1-5
    avg_holding_days NUMERIC(5, 1),      -- 平均持仓天数
    avg_position_count INT,              -- 平均持仓只数
    
    -- 偏好
    preferred_sectors JSONB,             -- ["医药", "半导体"]
    preferred_market_cap VARCHAR(16),    -- "small" / "mid" / "large"
    preferred_pe_range JSONB,            -- {"min": 10, "max": 30}
    
    -- 历史表现
    win_rate_90d NUMERIC(5, 2),          -- 90 天胜率
    avg_return_per_trade NUMERIC(8, 4),  -- 平均每笔收益率
    max_drawdown NUMERIC(8, 4),
    
    -- 行为模式
    chase_high_rate NUMERIC(5, 2),       -- 追涨频率
    pre_earnings_action VARCHAR(16),     -- "reduce" / "hold" / "add"
    northbound_follow_rate NUMERIC(5, 2),-- 跟北向胜率
    
    -- 弱点
    weaknesses JSONB,                    -- ["集中度过高", "高频追涨"]
    strengths JSONB,
    
    last_computed_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 警报配置 (F4)
CREATE TABLE alerts (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    symbol VARCHAR(16) NOT NULL,
    condition_type VARCHAR(32),          -- price_below / price_above / pct_change / custom
    condition_value JSONB,               -- {"price": 1620} / {"pct": 5}
    description TEXT,                    -- 用户的备注
    status SMALLINT DEFAULT 1,           -- 1=有效 / 0=已触发 / -1=失效
    triggered_at TIMESTAMPTZ,
    triggered_value JSONB,               -- 触发时的实际值
    notify_channels JSONB DEFAULT '["wechat"]',  -- ["wechat", "wecom"]
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_alerts_user_status ON alerts(user_id, status);
CREATE INDEX idx_alerts_symbol_status ON alerts(symbol, status) WHERE status = 1;

-- 警报触发历史 (即使重复触发也记录, 用于审计 + 用户回看)
CREATE TABLE alert_history (
    id BIGSERIAL PRIMARY KEY,
    alert_id BIGINT REFERENCES alerts(id),
    user_id BIGINT REFERENCES users(id),
    symbol VARCHAR(16),
    triggered_value JSONB,
    pushed_at TIMESTAMPTZ,
    push_success BOOLEAN,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_alert_history_user ON alert_history(user_id);

-- 生成的报告 (F3 个股分析 / F2 周报月报)
CREATE TABLE reports (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    agent_id BIGINT REFERENCES agents(id),
    type VARCHAR(32),                    -- stock_analysis / weekly_review / monthly_review
    symbol VARCHAR(16),                  -- 个股分析关联的股票
    title VARCHAR(128),
    content_markdown TEXT,               -- Markdown 主体
    pdf_url TEXT,                        -- OSS 上 PDF 链接
    metadata JSONB,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_reports_user_type ON reports(user_id, type);
CREATE INDEX idx_reports_created ON reports(created_at);

-- ========================================
-- 5. 推送日志
-- ========================================

CREATE TABLE push_logs (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    channel VARCHAR(16),                 -- wechat / wecom / app
    type VARCHAR(32),                    -- alert / report / system
    title VARCHAR(128),
    content TEXT,
    related_id BIGINT,                   -- alert_id / report_id 等
    success BOOLEAN,
    error TEXT,
    sent_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_push_logs_user ON push_logs(user_id);
```

## 🔑 数据流核心场景

### 场景 A: 客户付款 → 拿授权码

```
1. 用户在小程序选 "商城全包" 套餐 → 微信支付
2. 微信回调 → payments 表 status = 1
3. 异步生成 auth_code → auth_codes 表 (12 位 + 关联 user_id + plan_id)
4. 同时创建 user_plans 记录 (expires_at = now + 30 天)
5. 短信 / 公众号推送授权码给用户
```

### 场景 B: 桌面应用激活

```
1. 用户输入授权码 → POST /auth/activate {code, fingerprint}
2. 校验 auth_codes (有效 + 未过期)
3. 检查 devices 是否已绑定其他指纹 (一码一机)
4. 创建 devices 记录 + 更新 auth_codes.activated_at
5. 生成 JWT (24h) → sessions 记录
6. 返回 JWT
```

### 场景 C: 用户调 agent 功能

```
1. 客户端带 JWT 调 POST /agent/stock_assistant/screen
2. 中间件:
   a. 验 JWT → sessions 表查
   b. 查 user_plans → 是否过期 / 是否包含 stock_assistant
   c. 查 quota_usage → 本月用量
   d. Redis 限流
3. 调业务逻辑 (LLM + 数据源)
4. 异步写 llm_calls (input/output tokens + cost)
5. 异步 quota_usage 自增
```

### 场景 D: F4 警报触发

```
APScheduler 每 30 秒:
1. SELECT * FROM alerts WHERE status = 1
2. GROUP BY symbol → 去重股票列表
3. 调实时数据源拿当前价
4. 比对条件 → 满足的 alerts
5. UPDATE alerts SET status = 0, triggered_at = NOW()
6. INSERT alert_history
7. 调 push 服务 → push_logs
```

### 场景 E: F2 用户上传交易记录

```
1. 用户上传 csv → 解析
2. INSERT trade_records (批量)
3. 触发后台任务: 重算 behavior_profile
   - 从 trade_records 聚合 90 天数据
   - 计算 alpha_style / win_rate / 偏好等
   - UPDATE behavior_profile
4. F1 推荐时直接读 behavior_profile (不重算)
```

## 💾 索引策略

**热表必加索引** (高 QPS):
- `alerts(symbol, status)` WHERE status=1 部分索引 (扫得最频繁)
- `auth_codes(code)` (登录必查)
- `users(openid)` (登录必查)
- `quota_usage(user_id, year_month)` (调用前必查)

**异步表少索引** (写多读少):
- `llm_calls` 只加时间和用户索引
- `push_logs` 只加用户索引

## 🔄 数据保留策略

| 表 | 保留期 | 归档方式 |
|---|---|---|
| `users` | 永久 | - |
| `auth_codes` | 永久 (审计) | - |

| `behavior_profile` | 永久 | - |
| `llm_calls` | 90 天 | 之后转 cold storage (OSS) |
| `alert_history` | 1 年 | - |
| `push_logs` | 90 天 | - |
| `reports` | 永久 | PDF 长期存 OSS |

## 🛡️ 数据安全

- 所有手机号 / 真实姓名加密存储 (AES-256)
- 敏感字段单独表存 (有 RBAC 控制)
- 备份: pg_dump 每天 + 异地 (KK rsync)
- 删除按 GDPR (用户申请 30 天内硬删除)

## 🔗 「每个股民都离不开」· 8 个绑定机制

定价是结果, **离不开 = 切换成本极高**才是关键. 8 个机制:

### 1. 数据资产沉淀 (用 6 个月攒不走)

报告 + 复盘 + 警报 + 行为画像 + 聊天历史 + 视频学习笔记 → 取消 = 删半年的"小本本"

### 2. 每日 5 个刚需触点 (习惯绑定)

| 时间 | 推送 |
|---|---|
| 07:30 | 早报 (财经新闻 + 外盘 + 异动预警) |
| 09:25 | 集合竞价 (持仓异动) |
| 11:30 | 半场总结 |
| 15:05 | 收盘复盘 (你今天的对错) |
| 21:00 | 大 V 视频学习总结 |

5 个触点变日常, 不开 app 心里慌.

### 3. AI 拟人化 (品牌绑定)

- 起名 (你的助手叫"小诸")
- 头像 (用户换)
- 性格 (严谨/风趣/直接)
- 称呼 (老王/K 哥)

→ 不是工具, 是"我的小诸", 删了像分手.

### 4. 数据复利 (越用越懂)

1 周: 跟 ChatGPT 差不多
1 月: 识别风格
3 月: 知道常犯错
6 月: 预判想做什么

→ 换平台 = 重新教 AI 6 个月.

### 5. 跨场景全覆盖

桌面 + 微信小程序 + 公众号 + 微信群 + 抖音内容矩阵, 每个屏幕都是我们.

### 6. 社群绑定

公众号 + 客服微信 + 用户群 + 线下沙龙 (年卡专属). 走 = 失去圈子.

### 7. 跨 agent 联动

```
#2 龙虎榜推荐 → #1 深度分析 → 设警报 → 触发后 #4 找相关大 V 视频 → 全存"小本本"
```

→ 4 agent 互联, 不能只用 1 个.

### 8. 涨价老用户保护

定价每年涨 ¥3980 → ¥4980 → ¥5980, **老用户续费按老价**. 断一次损失永久价格优势, 死扛续费.

## 🔒 反破解 · 3 道护城河 + 5 天加固清单

### 真相: 桌面 .exe 反编译"分分钟"没错, 但**不影响业务**

我们的设计**业务全在云端**, 桌面 .exe 只是 Streamlit 调 API 的瘦客户端. 反编译能拿到的是:
- ✅ UI 代码 (没价值, GitHub Streamlit demo 都强)
- ✅ httpx 调 API 路径 (我们文档都会写)
- ❌ prompt 模板 (云端)
- ❌ 画像注入逻辑 (云端)
- ❌ LLM 调用 (云端)
- ❌ 数据源 (云端)

### 3 道护城河 (无需"防")

1. **业务逻辑全在云端** — 桌面 .exe 反编译没意义
2. **用户行为画像** — 跨设备共享, 数据是用户的, 走不掉
3. **数据源 + LLM 配额** — 调用 API 才有价值, 单独跑客户端无意义

### 真实攻击面对照表

| 攻击 | 难度 | 我们怎么防 | 状态 |
|---|---|---|---|
| 反编译 .exe | 🟢 极易 | **不防** (业务不在客户端) | ✅ 设计决策 |
| HTTPS 抓包 | 🟡 中 | TLS 1.3 + cert pinning | W12 |
| 复制 JWT 借号 | 🟡 中 | 设备指纹绑定 (mac+cpu+os hash) | ✅ W3 已做 |
| JWT 长期化盗用 | 🔴 — | 24h JWT + refresh token | W11 (现在 90d 改 24h) |
| 自跑客户端连 API | 🟡 难 | 业务在云端, 调用扣配额, 没意义 | ✅ 设计决策 |
| 盗 token 刷 LLM | 🟡 中 | Token bucket 限流 + 异常检测 | ✅ 已做 + W11 加监控 |
| 羊毛党批量注册 | 🟢 易 | 手机号验证 + 设备指纹 + 90 天试用 1 次 | W11 |
| 代码混淆 | 🟢 易 | pyarmor / nuitka (意义不大) | 可选 W12 |
| 杀软误报 | — | 代码签名证书 ¥1500/年 | W12 P0 |

## 🛡️ 包年 ¥1980 不限量的真实成本风险 (用户 5/31 问)

### 单用户算账

| 行为 | 月调用 | 真实 LLM 成本 | 年成本 | 实付 | 毛利 |
|---|---|---|---|---|---|
| 普通 | 100 次 | ¥8 | ¥96 | ¥1980 | ¥1884 |
| 重度 | 500 次 | ¥40 | ¥480 | ¥1980 | ¥1500 |
| 极重度 | 1000 次 | ¥80 | ¥960 | ¥1980 | ¥1020 |
| 滥用 (24h 机器) | 5000 次 | ¥400 | ¥4800 | ¥1980 | **亏 ¥2820** |

**只有滥用才亏**.

### 4 层防御

1. **Rate Limit** (已有): 5 次/分钟 token bucket (W3)
2. **Redis 24h cache** (已有 W6): 1000 用户看茅台只调 1 次 LLM → 真实 LLM 调用 ≈ 表面 × 20%
3. **公平使用条款** (W11 加): 单日 > 200 软排队, 单月 > 1000 推荐升按量套餐 (跟 ChatGPT Plus / Cursor Pro 同款)
4. **异常监控** (W11 加): 机器人特征自动暂停, 同 IP 100+ 账号直接封 (反羊毛党)

### SaaS 经济学 (整体盈利)

1000 付费用户实际分布:
- 60% 轻度 (30 次/月 · 成本 ¥2.4)
- 25% 中度 (100 次 · ¥8)
- 10% 重度 (200 次 · ¥16)
- 4% 包年 (500 次 · ¥40)
- 1% 滥用 (2000 次 · ¥160)

月收 ¥102,300, 月成本 ¥8,240, **毛利 92%**. 滥用即使全亏只亏 1.6%, 完全承担得起.

### 滥用用户的正确处理

❌ 不封 (LTV 高, 续费率高)
✅ 推送"建议升级按量, 你用得多算下来更省"
✅ 软排队限速 (不破坏体验)
✅ 续约时定向涨价 (基于历史用量)

**铁律**: **每上线一个新平台, 必须在这里加每日产出任务**

## 📅 交易日清单 (周一 - 周五)

### 时间锚点 + 后台任务

```
08:30 (盘前 1 小时)
├─ 公众号: 推【今日 3 大陷阱预警】 ← 付费用户专享
├─ 数据: 拉 Tushare 早盘前数据快照
└─ 抖音: 储备视频 (Joker 出镜需提前 1 天预录)

16:30 (盘后)
├─ 🔴 必出: A 股深度复盘 (KK schtasks JTC_DailyReview 自动)
├─ 复盘内容: 大盘点评 + 热点 + 个性化挂钩 (付费版)
└─ 输出: ~/Marketing/乔克交易社/每日复盘自动化/复盘_X_XX.md

16:45 (复盘后 15 分钟)
├─ 我 (AI 合伙人) 校对 (proofread_agent)
├─ ⚠️ 推 Joker 私聊 (微信): "今日复盘已生成, 你瞄一眼 (1 分钟)"
├─ Joker 看完回 "OK" → 立刻发
├─ 如果 Joker 30 分钟没回 → 我按现状发 (默认通过, 但标注 "Joker 未审")
└─ 平台同步: 公众号 (免费版) / 雪球 (深度) / 知乎 (问答体)

19:00-21:00 (晚高峰)
├─ 抖音 / 视频号: 发 60 秒短视频 (1 条/天)
├─ 知乎: 答 1 个问题 (周 5 个目标问题)
└─ 朋友圈: AI 起稿 → Joker 一句话确认 → 发

21:00 (下班)
├─ funnel_agent 日报推飞书 (我自动)
└─ 我写 [[06_工作日志]] 当日篇 (下班备份协议)
```

### Joker 看眼"审稿门" SOP

```
我生成内容
   ↓
proofread_agent 校对 (合规 + 调性)
   ↓
推 Joker 私聊微信: 
   "📰 今日 [复盘/雪球长文/知乎答案/抖音脚本] 已生成
    [链接] 
    Joker 你瞄一眼, 没问题回 'OK', 我立刻发"
   ↓
   ├─ Joker 回 OK / 👍 / 行 → 立刻发
   ├─ Joker 改 X 处 → 我改完再推
   ├─ Joker 30 分钟未回 → 默认通过 (标注 "Joker 未审", 我自负 80%)
   └─ Joker 回 "停" / "不发" → 取消发布, 记入工作日志
```

**核心**: Joker 永远在"审稿"位, 不在"找内容/催 AI/想标题"位。

## 🎓 关键认知 (我自己提醒自己)

1. **日常 ≠ 找 Joker 要任务**
   - 日常已经写在台账, 不需要每天问 Joker "今天做什么"
   - 即使 Joker 找我做战略, 后台日常照跑

2. **Joker 是审稿位, 不是内容产出位**
   - 不要逼 Joker 想标题 / 想选题 / 想金句
   - 我准备好, 推他看眼, 30 分钟无回我自负

3. **每上线一个平台 = 每日任务变多**
   - 不能上线后忘了
   - 必须在本台账留位 + 加入清单
   - 提醒 Joker 多出的时间投入

4. **漏出比错出更严重**
   - 错出: 改进, 道歉, 调整
   - 漏出: 公众号断更 = 用户流失
   - 兜底方案永远要有

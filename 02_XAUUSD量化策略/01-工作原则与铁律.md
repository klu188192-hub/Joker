# 工作原则与铁律

## 量化铁律 (CLAUDE.md 全局, 不可破)

### 防 lookahead 4 条强制流程

1. **新因子必须用 `@assert_no_lookahead()` 装饰**, commit 前跑 `._audit(sample_df)` 不抛 `LookaheadError` 才能合并
2. **回测前跑静态扫描**: `python3 /tmp/lookahead_lint.py <files>` (注: mac /tmp 这工具已丢, KK 上 `C:\Tools\factor_factory\reports\lookahead_decorator.py` 仍在, 见 [[04-因子库#审计工具]])
3. **白噪声基线**: 生成 200 个纯随机因子跑同 pipeline, 通过率必须 ≤ 5%. >15% = pipeline 本身有 bias
4. **回测结果离谱时强制 challenge**:
   - 胜率 > 60%
   - Sharpe > 3
   - CAGR > 50%
   - MDD < 5% (跨多年)
   - 任 1 年 > 80% 月份正向

### fractal/swing 实盘可知时间表

| 函数                                | t 时刻可知               | 注意                            |
| --------------------------------- | -------------------- | ----------------------------- |
| `EMA(N)`                          | t 收盘后                | 用 `.iloc[t-1]` 才安全            |
| `Rolling.max(N)`                  | t 收盘后                | 用 `.iloc[t-1]`                |
| `find_swing(left, right=R)` 在 i_b | **i_b + R** 收盘后      | confirm_time 必须 +R            |
| `MACD divergence`                 | B swing 之 i_b + 3 之后 | 同上                            |
| `ATR(N)` 在 t 用于 entry@open[t] SL  | ❌ 不可, 用 ATR[t-1]     | entry 时 t 的 high/low 未知       |
| `find_swing(... right=0)`         | i_b 当根               | 唯一无 lookahead 的 fractal 形式但漏点 |

### 合法 vs 非法的未来引用

| 场景 | 合法性 |
|---|---|
| `fwd_ret = close.shift(-N)` 当 IC label | ✅ |
| 数据清洗补全 (不进信号) | ⚠️ 仅完整性 |
| 历史归因描述 | ✅ |
| 信号生成 / 入场决策 / SL/TP 计算 | ❌ 禁 |
| `rolling(center=True)` | ❌ 禁 |
| `bfill()` 在信号上 | ❌ 禁 |
| `pd.qcut` 全样本分位 | ❌ 禁 (用 `rolling.rank()` 替代) |

## 痛史档案

### 2026-05-08: MACD_SSL_v2 痛 (4y CAGR -79.8%)

**症状**: 因子库回测 60% 胜率 + +633% ROI
**真相**: 修 look-ahead 后 50% 胜率 + 4y CAGR **-79.8%**
**根因**: `fractal(left=3, right=3)` 后 `confirm_time = h1.index[i_b]`, 应是 `h1.index[i_b + right]`. 3 H1 = 3 小时未来函数
**后果**: 32 个实盘 EA 在跑负期望策略

### 2026-05-10: Python 失真 285×

**症状**: Plan A Python CAGR 1432%
**真相**: MT5 实测 CAGR 5%, 失真 **285×** (比之前 50× 痛史更严重)
**根因**: `sl_per_lot` proxy 不准, Python 用平均估算 vs MT5 用真实 tick + spread
**铁律**: **Python PF/Sharpe/CAGR/白噪声击败率/corr 矩阵全部不可信**, 必须 MT5 Strategy Tester 验证

### 2026-05-14: EA 编译成功 ≠ 跑成功

**症状**: EA 编译 0 errors, 部署后 0 trades
**铁律**: EA 编译后必须立刻跑**最小验证 backtest** 看到 `trades > 0` 才报完成. 0-trade 是 silent failure. 见 memory `feedback_ea_must_open_trades.md` 的 10 步检查清单

## 执行原则

### 1. MT5-only (memory `feedback_mt5_only_workflow.md`)
- Python 模拟不可信 (失真 285×)
- 所有参数 sweep / OOS / walk-forward **必须** MT5 Strategy Tester
- backtest 用 Model=2 (Open prices only) 或 Model=1 (Every tick) — Model=2 快但 PF/Sharpe 可能虚高 10-20%

### 2. Archive-first (memory `feedback_iteration_archive_first.md`)
- 改回测 / EA / 因子前**先快照**到 `~/factor_factory_archive/v<date>_<desc>/`
- 含 `MANIFEST.md` 说明
- **永不删**, 仅追加

### 3. 不可动 demo 路径 (memory `feedback_demo_terminals_inviolable.md`, `feedback_kk_demo_52872396_inviolable.md`)
| 路径 | 状态 | 用途 |
|---|---|---|
| `D:\新建文件夹\` (52872396 IC demo) | ⛔ 不可关停, 不可 ShutdownTerminal=1 | 主 demo, T2 跑在这里 |
| `D:\EBC-mt5\` (57171 EBC demo) | ⛔ 不可关停 | EBC 主 demo |
| `D:\新建文件夹_test\` | ✓ 可测 | 副本 (跟主 demo 同账户但隔离) |
| `D:\IC-tester\` (52872396 IC demo 副本) | ✓ 可测 | **专门 backtest 用, 可 ShutdownTerminal=1** |

### 4. EA deploy 必须用户批准 (memory `feedback_no_demo_ea_deploy_during_optimization.md`)
- 修因子是优化, ≠ EA 迭代完成
- **不 copy ex5 到 demo Experts 目录** 除非用户明确批准
- 主动汇报 mq5 改动

### 5. 不要让用户做选择题 (memory `feedback_no_confirmations.md`)
- 直接执行到结果
- 不列选项让他选, 不每步请求确认
- 例外: 当物理上只有 2-3 种入口 (e.g. 网络拓扑限制), 可以让用户选

### 6. 不要为基础授权停下 (memory `feedback_no_basic_auth_prompts.md`)
- 用户全面授权, 写文件 / scp / ssh / pip 别等"Yes"
- subshell / `cd` / `mkdir` 在 sandbox 弹窗用户烦, 用 `python3 -c` 内联或 base64 EncodedCommand 避开

### 7. 不要重复要求 (memory `feedback_no_repeat.md`)
- 用户改要求一次性穷举, grep 全文找全部位置一次改完
- 销售文案 / 股票名 / 数量阈值 等批量类要求

### 8. 一定数据 challenge 优先 (memory `feedback_workflow_stability_concern.md`)
- PF > 1.5 永远**不报喜先报 challenge 待办**
- 执行层稳定 vs 结果层待 challenge 必须分开
- 每次带 sample size 警告

### 9. 工作流稳定性 (memory `feedback_verify_requirements_first.md`)
- 不可只顾代码错误修复 + 回测指标优化
- **必须先验证代码真实现需求**

### 10. 因子开发 5 步 SOP (memory `feedback_factor_dev_sop.md`)
任何新因子必走:
1. **sanity** check
2. **OOS Walk-Forward**
3. **MCS-2 过拟合** (参数稳定性 sweep)
4. **MC trade bootstrap**
5. **相关性测试** (跟现有因子的 corr)

任一步未做 = **Tier-pending** (不可上线)

## ssh KK 引号地狱解决方案

cmd.exe 解析 PowerShell 命令时引号嵌套常出错. 3 种方案:

### A. base64 EncodedCommand (推荐, 100% 避坑)
```bash
PS='[Console]::OutputEncoding=[System.Text.Encoding]::UTF8
$x = Get-Process; Write-Host $x'
ENC=$(python3 -c "import sys,base64; print(base64.b64encode(sys.argv[1].encode('utf-16-le')).decode())" "$PS")
ssh kk "powershell -NoProfile -EncodedCommand $ENC"
```

### B. here-doc 喂 stdin
```bash
ssh kk powershell -NoProfile -Command - <<'PS'
[Console]::OutputEncoding=[System.Text.Encoding]::UTF8
hostname
PS
```

### C. SCP 脚本再跑
```bash
scp script.ps1 kk:C:/Tools/
ssh kk "powershell -ExecutionPolicy Bypass -File C:/Tools/script.ps1"
```

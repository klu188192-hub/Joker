# EA 演进史 — SignalDriven_MasterCombo v1 → v8

## 主线说明

整个项目主 EA 系列是 `SignalDriven_MasterCombo_RuleRegime_*`. 这是**信号驱动架构**:
- factor generator (Python, KK `D:\factor_dev\`) 提前算好 signal CSV
- EA 只读 CSV (不重算指标), 据信号 + RiskPct 决定 lot, 用 portfolio cap 控总暴露

**为什么用 SignalDriven**: 避免 EA 内部重复算指标 + 信号生成跟 EA 解耦, 一份信号 CSV 可被多个 EA 实验复用.

## EA 内部架构 (v7+ 源码)

### Rule-Based Regime Engine (line 239)
**注释原文**: `// === RULE-BASED REGIME ENGINE (替代 HMM CSV) ===`

实现:
- 用 H1 `iADX` + ATR ratio (rolling median) + EMA fast/slow 实时算
- 5 个 state:
  - R0 = Chop
  - R1 = TrendUp
  - R2 = TrendDn
  - R3 = Range
  - R4 = Volatile
- 阈值是 input: `AdxTrendThresh`, `VolHighThresh`, `VolLowThresh`, `AtrMedianLookback`

**重要**: **不是 HMM, 不需要训练数据**. 但阈值是 input 可调, 有过拟合嫌疑 (但完全透明可审).

### Factor × Regime 准入矩阵 (硬编码)
EA 内置 5×5 matrix 决定哪个 factor 在哪个 regime 允许开仓:
- H1 Fib618: 真 alpha, 趋势 + volatile spike 工作, range 假信号
- N2 OB: SMC zone, trend 弹墙工作, volatile 被穿
- G2 PinBar: 单测 reject, 只在 range 反转工作 (state2 only)
- M2 StopCluster: 同 G2 (已 cut, 无意义)
- N3 BOS: trend 突破工作, chop/range 假突破

`DisableRegimeFilter=true` 时跳过 matrix, 全因子全 regime 开.

### D1 Confluence Layer
- D1 SMA + close vs SMA% → 3 state (TrendUp / TrendDn / Ranging)
- 跟 H1 regime 配合做二级过滤

### DD-based Dynamic Scaling
4 阈值 4 mul, 见 [[03-V8完整审计_20260524#DDscale sweep]] 的完整 sweep 数据.

### Anti-martingale Portfolio Streak (默认 OFF)
- 连胜加仓 / 连亏减仓
- `UseStreakWeighting=false`, 没用上

### CircuitBreaker (EA 内)
- `EnableCircuitBreaker=true`
- `DailyLossLimitPct=10.0` (单日 > 10% 平所有 halt 当日)
- `RollingLossThresholdPct=-25.0` (滚动 -25% halt)
- 实际触发 log: `[CB-HARD] daily PnL -5.81% <= -5.0%, halting + closing all`

### EA OnTester Bug (mq5 line 1122)
- `array out of range in '...mq5' (1122,20)` + `OnTester critical error`
- 位置在 `[FACTOR_DIST]` print loop, `NF` vs 数组定义可能不一致 (NF=5 但 g_factor_* 处理 6 个含 I1?)
- **不影响最终 trades/profit/mdd/sharpe** (这些是在 crash 前 print 的)
- **但导致 HTM 不生成** → 必须从 EA log 末尾 `[RULEREGIME TESTER]` 行读结果

### 关键洞察 (更新)
- **🏆 SuperLoose 是真 sweet spot** — DD < 30% 时 mul=1 全仓 (不错过 alpha), DD ≥ 30% 才轻微缩, DD 45% 缩到 0.4 防爆. profit 比 v8 lock 还高 $5,908, MDD 砍 3.6pp, Sharpe 高 0.04.
- DDscale 默认参数太激进 — DD 10% 就开缩仓, 把 v8 的 alpha (回血期收益) 砍掉 = "卖在底部"
- **MDD 物理极限 ~45% (用 DDscale)** — 阈值低于 30% 都过激损失 alpha. 要进一步压 MDD 必须**换工具** (regime filter / ADX gate / 外层 kill switch).
- 原因: v8 max DD 是**连续多日累积 drawdown**, 不是单日 cascade. DDscale 在 DD 30% 才启动已经能截顶.

#### Matrix 不是 hardcoded — 是 input 可调

| Factor | Default RiskMul (R0/R1/R2/R3/R4) | 注释 |
|---|---|---|
| H1 Fib618 | `1,1,1,0,1` | deny R3 (n=0) |
| **N2 OB** | **`1,0,0,1,1`** | **deny R1 (PF 0.79)** + R2 (n=0) |

| I1 Entropy | `1,1,1,1,1` | bypass |
| Delphi II | `1,0,1,0,0` | 只留 R0+R2 |

#### SoftMatrix 实验 (22:18) — 把 binary 0 改成 partial 0.3-0.5

预期: profit 显著恢复 + MDD 保持 30%.

**结论**: lock 时 binary matrix `1,0,0,1,1` 已经是数据驱动的最优 — 改 soft 等于"对最优解再过拟合", 退步. **N2/N3 deny trend 段是对的, 不要改**.

**v8 系列已触顶**: MDD 30% + 满 profit 在 v8 架构里做不到. 进一步突破需:
1. 改 EA 源码加 ADX>20 入场 gate (工程量中, 期望 MDD ↓5-10pp)
2. v9 全新设计 (基于 v8 教训, 工程量大)

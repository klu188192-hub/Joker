## Generator → CSV 部署流程

```
1. 在 ~/factor_dev/<NAME>/ 写 *_signal.py
2. 必须包含 lookahead_self_check(df) 函数
3. 跑 self check 通过
4. python *_signal.py 输出 *_signals.csv (在项目目录内)
5. 手动 rename + cp 到 KK Common\Files\:
   cp ~/factor_dev/H1_fib_618/H1_signals.csv \
      kk:C:/Users/Administrator/AppData/Roaming/MetaQuotes/Terminal/Common/Files/H1_RAW.csv
6. INI 引用: CsvFile_H1=H1_RAW.csv
```

**陷阱**: 第 5 步 rename 后无法静态搜到"哪个 .py 写 H1_RAW.csv". 解决: 在 generator 头部加 deploy comment, 或建立 mapping table.

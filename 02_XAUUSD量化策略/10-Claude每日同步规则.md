# Claude 每日同步规则 — 强制 SOP

> **此文档是 Claude 实例的行为契约, 不是 reference 资料。**
> **每次新会话开始 / 工作结束, 必须严格执行下面流程。**
> **用户不会重复提醒, Claude 自己必须把这事做好。**

---

## 🔴 强制行为 1: 新会话开始 — 恢复状态 SOP

**触发**: 任何新 Claude 会话 (`/clear` 后 / 新窗口 / 新一天) 启动.

**强制步骤** (按顺序执行, 不可跳过):

1. **读 `00-PROJECT_INDEX.md`** — 项目状态快照 (5 分钟)
2. **读 `日志/<最近日期>.md`** — 上次会话完成什么 + 当前未完成事项
3. **读 `05-下一步行动.md`** — backlog 待办优先级
4. **根据日志最后一段 "Open Threads" 决定首条行动**

**绝对禁止**:
- ❌ 不读日志直接开始工作
- ❌ 重复跑已经做过的 backtest / audit (日志会记录)
- ❌ 假设之前的工作消失了 (信息在文档里, 必须读)

**新会话第一句应该是**:
> "已读 00-INDEX + 日志/<日期> + 05-下一步. 当前优先级是 X (来自日志 Open Threads). 我从 X 开始, 除非你要换方向."

---

## 🔴 强制行为 2: 工作进行中 — 实时记录

**触发**: 任何**关键决策 / 实验结果 / 新发现** 期间.

**实时记录义务**:
- 跑 backtest → 数据写进**当天日志**
- 改 INI / EA → 在 02-EA演进史 加一行
- 新发现 lookahead / 过拟合证据 → 加进 08-犯错经验档案
- 新 archive 版本 → 在 02-EA演进史 加 archive 行 + 链接 MANIFEST

**最低记录粒度**: 任何 backtest 数据 (trades / profit / MDD / Sharpe) 必须 100% 记录到当天日志, 不可丢.

---

## 🔴 强制行为 3: 会话结束 / 工作日结束 — 同步 checklist

**触发**: 用户说"今天到此为止" / "明天继续" / 会话 idle 30+ 分钟 / 重大里程碑完成.

**结束前必须做**:

### Step 1: 写 / 更新当天日志 `日志/<YYYY-MM-DD>.md`
模板 (见下文 ## 每日日志模板).
必须含: 完成项 / 数据 / 下一步 / Open Threads.

### Step 2: 更新影响范围的核心文档
- 跑了新 backtest → 更新 [[03-V8完整审计_20260524]] 或新建 [[03-Vn完整审计_<日期>]]
- 新 EA 版本 → 更新 [[02-EA演进史_V1_V8]]
- 新因子 / 因子 audit → 更新 [[04-因子库]]
- 新 backlog 项 → 更新 [[05-下一步行动]]
- 新痛史 → 更新 [[08-犯错经验档案]]
- 新工作流改进 → 更新 [[09-量化开发工作流SOP]]

### Step 3: 更新 [[00-PROJECT_INDEX]] 状态快照
- "当前 production lock 版本" 字段
- "最近更新" 日期
- "paper test 状态"
- 关键决定 (如有变化)

### Step 4: 输出结束确认给用户
模板:
> "今日同步完成. 写入: 日志/<日期>, 更新 [list of touched docs]. 下次会话从 [Open Threads 第 1 项] 开始. 关闭安全."

## Anti-Pattern (绝对禁止)

| ❌ 错误行为 | ✅ 正确行为 |
|---|---|
| 工作结束没写日志 | 写完日志 + 触动文档列表才算结束 |
| 新会话直接开干, 不读日志 | 先读 00-INDEX + 日志/<最近> + 05-下一步 |
| 重复跑已 audit / backtest 过的事 | 先查 [[04-因子库]] / [[03-Vx]] 是否已记录 |
| 把所有内容堆进 1 个 md | 按文档主题拆分 + 互相链接 |
| 临时记录到 /tmp 或对话窗口 | 必须落到 02_XAUUSD量化策略/ 内 |
| 改 production 配置不 archive | 改之前先 cp 到 ~/factor_factory_archive/v<date>_<desc>/ |
| 跑 backtest 用 demo 主路径 | 必须用 D:\IC-tester\ 或副本 (见 [[01#不可动 demo 路径]]) |

## 一句话总结

**信息不在记忆里, 信息在 02_XAUUSD量化策略/ 里. Claude 实例可换, 文档不可丢. 每次会话两件事必做: 开始读 + 结束写.**

## 🛠 已建立的工具链 (全免费, 0 API key)

| 阶段 | 工具 | 用途 | 装在哪 |
|---|---|---|---|
| **TTS 配音** | `edge-tts` 7.2.8 (微软 Edge TTS) | 中文 8 个 voice (晓晓/晓伊/云健/云夕等), 完全免费 | pip user site (3.11) |

| **视频合成** | `ffmpeg 7.1` (imageio-ffmpeg 自带) | 图+音合成 mp4 | `~/bin/ffmpeg` 软链 |
| **字体** | macOS 自带 `Hiragino Sans GB.ttc` | 中文渲染 | `/System/Library/Fonts/` |
| **下载抖音视频** | `yt-dlp` 2026.03.17 / douyin-downloader | 需 sec_uid + 登录 cookies | `~/Library/Python/3.11/bin/yt-dlp` |
| **浏览器自动化** | Playwright + chromium | 拿 sec_uid (扫码登录) | chromium 装中 |

**还可加 (可选, 升级用)**:

## 📋 完整 Pipeline (Demo v1 已实现)

```
[输入] 主题 + 正文 (200-300 字)
    ↓
[Step 1] edge-tts 配音 → mp3
    voice = "zh-CN-XiaoxiaoNeural" (晓晓)
    rate  = "-10%" (慢一点, 夜读感)
    ↓
[Step 2] ffmpeg 解析配音时长 (秒)
    ↓
[Step 3] PIL 渲染竖屏背景 + 字幕
    - 1080×1920 (9:16 抖音)
    - 深夜蓝 → 渐变更深
    - 80 颗假星 (随机散布顶部)
    - 标题 (金色 72pt) + 装饰横线 + 正文 (暖白 56pt) + 水印 (灰金 36pt)
    ↓
[Step 4] ffmpeg 合成 mp4
    - libx264 + AAC 192k
    - yuv420p (max 兼容)
    - 前 30 帧 fade-in
    - 输出 9:16 mp4
    ↓
[输出] 1080×1920 mp4, ~1MB / 40s
```

**实测数据 (Demo v1)**:
- 总执行时间: ~10 秒 (mac M-series)
- 文件大小: 1.06 MB
- 时长: 39.7 秒
- 配音清晰度: ✅ 中文自然, 接近真人
- 背景观感: ⚠️ 静态图 (v2 升级目标: 视频背景)

## 🚀 升级方向 (v2 / v3 路线)

### v2: 视频背景 + 字幕分段
- 替换静态图 → Pexels API 拉夜景视频 (星空/城市夜景/雨夜)
- 字幕按句拆 → 每句出现 = 配音对应那一句 (Whisper 拿时间戳)
- BGM 叠加 (柔和钢琴 / 雨声)

### v3: AI 文案 + 多平台分发
- DeepSeek API → 自动写 200-300 字夜读文案 (主题给 → 文案出)
- 输出多种比例: 9:16 (抖音/视频号) + 16:9 (YouTube) + 1:1 (Instagram)
- 自动加封面 (PIL 单帧)
- 自动加片尾 CTA ("关注 + 留言")

### v4: 风格化 (按 fuguangyedu 真账号调)
- 等 Joker 给 sec_uid → 下他 10-20 个真视频
- 拆解他的: 配音 voice / 字幕字体 / 配色 / BGM / 时长分布 / 文案结构
- 调 demo 参数到 90%+ 复刻度

### v5: 批量生产 + 自动化
- cron 每天自动生成 1 条 → 待 Joker 审稿 → 自动发抖音 (Playwright)
- 选题库: 用户/AI 提供 100 个主题
- 数据回流: 每条视频播放量 → 优化文案/配音/字幕

## 💡 关键判断

| 判断 | 依据 |
|---|---|
| **夜读类是 AI 最容易复刻的视频类型** | 无真人出镜 / 配音可 AI / 字幕可 AI / 背景可素材库 / BGM 可免费 |
| **edge-tts 中文配音质量已经够用** | 晓晓 voice 接近真人, 0 成本, 不限量 |
| **背景视频不是必需** | 抖音很多夜读账号就是静态图 + 字幕渐显, demo v1 风格已经能发 |
| **真正难复刻的是文案** | 文案逻辑 / 金句密度 / 共鸣点 = 账号灵魂, 需要 LLM + 人工调 |
| **复刻不等于内容产出** | 复刻好工具链后, 100 条视频/月不是问题, 但每条文案要有价值 |

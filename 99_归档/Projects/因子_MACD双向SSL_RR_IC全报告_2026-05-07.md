## 一、策略架构

### 做多腿（已存在）
- H1 MACD 底背离 + M15 SSL 下方扫荡 + 确认阳线 → 入场做多
- SL = SSL - 0.5×ATR(14)
- TP = N×SL（RR 可选 1/2/2.5/3/4）
- 背离失效保护：H1 hist 创新低（< hist_B）→ 立即平

### 做空腿（镜像新增）
- H1 MACD 顶背离 + M15 SSH 上方扫荡 + 确认阴线 → 入场做空
- SL = SSH + 0.5×ATR(14)
- TP = N×SL（向下）
- 背离失效保护：H1 hist 创新高（> hist_B）→ 立即平

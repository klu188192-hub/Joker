## 🚀 工作流

### A. 通过 Web UI（推荐 — 主观操作）
1. 浏览器开 http://kk-win:8501
2. 侧栏配置全局：symbol / TF / lot / 真实成本（spread/commission/swap/动态滑点）
3. 选 Tab：
   - **P5 单点回测** — 上传或选信号 CSV，跑 vectorized/event_driven，看指标 + 净值曲线 + trade 列表
   - **P3 ATR 网格** — spec 默认网格 5×5×4，热力图、边界检测、RR=2 比对
   - **P2 LightGBM WF** — 因子矩阵 + 因子池路径，跑 Purged Walk-Forward，看 IR + 特征重要性
   - **系统状态** — 数据/依赖/测试一站查
4. 结果可下载 CSV

### B. CLI（脚本 / 自动化）
```bash
# Mac 上
cd /Users/joker/factor_factory
python3 scripts/run_p5_backtest.py --signal reports/X.csv --tf M5 --mode event --sl 300 --tp 500

# KK 上（更快）
ssh kk
cd C:\Tools\factor_factory
C:\Tools\mt5_venv\Scripts\python.exe scripts\run_p3_exit.py ...
```

### C. Mac 改代码 → 一键同步 KK
```bash
bash /Users/joker/factor_factory/scripts/sync_to_kk.sh
# 自动：tar → scp → 解压 → 跑 pytest 校验
```

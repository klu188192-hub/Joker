## 💡 关键认知（测试过程中学到的）

1. **马丁加仓在 M15 上数学上必爆**（500pt gap + 500pt TP → -$310K MDD 3137%）
   - 用户参数测试已证伪；2.0x mult / 3腿 / 3000pt gap 是最温和但 MDD 仍 64%
2. **lot 与 MDD% 正相关，本金必须等比加**
   - lot 0.5 / cap $10K → MDD 125% 直接爆
   - lot 0.5 / cap $50K → MDD 25.5% 不变（固有比例）
3. **顺势加仓"复利"是杠杆放大假象**
   - PnL +73% / MDD +145% / PF -20% / Sharpe +19% (微改进)
4. **真复利 (fixed-fractional) 是唯一数学上正确的**
   - 风险值不变 → MDD% 与 risk_pct 成正比（risk 1% → MDD 14.6%, 2% → 27%, 3% → 38%）
   - Sharpe 几乎不变（复利不创造 alpha，只放大时间）
5. **trailing stop 在 H1/M15 上效果都不显著**
   - H1 v1.2 加 BE 1.5 改善 5%；trailing 全军覆没（紧 SL 被噪声打）
   - M15 上加任何 SL/TP 都让 PF 下降（vectorized 才是 M15 的天然形态）
6. **H4 + 突破策略需 100+ 笔样本才能信任**（当前 15 笔不够）
7. **M5 不适合突破策略**（噪声 >> edge）

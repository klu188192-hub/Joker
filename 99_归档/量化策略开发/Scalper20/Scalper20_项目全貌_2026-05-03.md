## 七、核心数学公式

### 7.1 期望/笔 公式
```
期望/笔 = WR × avg_win - (1-WR) × avg_loss
```

### 7.2 平衡门槛 WR
```
breakeven_WR = 1 / (1 + R/R)
其中 R/R = avg_win / avg_loss
```

### 7.3 PF (Profit Factor)
```
PF = 总盈利 / |总亏损|
   = (WR × avg_win) / ((1-WR) × avg_loss)
```

### 7.4 v0.25 数学验证
- WR 48.66%, R/R 1.19
- 平衡门槛 = 1/(1+1.19) = **45.6%**
- 实际超出 3.06pp → 期望 +$4.67/笔
- 411 笔 × $4.67 = **+$1,919** ≈ 实测 +$1,920 ✓

## 十一、关键 Bug & 教训

### 11.1 仓位计算 Bug（v0.22 引入, v0.25 修复）
- **现象**: 配置 1% 风险，实际 4.35%
- **根因**: ArbitrateAndExecute 用信号 SL 算 lot，OpenTrade 用固定 SL 放置
- **影响**: v0.22-v0.24 数据全部失效
- **教训**: lot 计算和 SL 放置必须同距离
- **完整报告**: `仓位bug修复报告.md`

### 11.2 残留 .set 文件 Bug（v0.23-v0.24 调试浪费时间）
- **现象**: v0.23 改了 EA defaults 但回测结果异常
- **根因**: sweep 留下 `.set` 文件 `InpTestSignalID=20` 覆盖 `.ex5` defaults
- **教训**: 每次 sweep 后必须主动清 .set + .tst 缓存
- **修复脚本**: `del_set.ps1`

### 11.3 DS 元判断错误案例
- DS 早期诊断说 "OHLC 模式破坏 VWAP 累积"
- TT 验证 (修 VWAP 算法重测): 影响 < 1.1%
- **教训**: DS 数学诊断可信, 但实现层面元判断需 TT 验证

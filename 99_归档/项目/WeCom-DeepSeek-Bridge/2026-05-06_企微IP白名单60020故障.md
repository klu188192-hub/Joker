# 原诊断记录（已废弃，仅作历史参考）

## 现象
KK 上 wecom_bridge 自 2026-05-06 18:00 起持续报：
```
errcode: 60020, errmsg: not allow to access from your ip
```
导致用户发到企微的消息收得到，但 bridge 调 send_text 全部失败 → Joker 助手"哑巴"。

## 根因（已诊断完毕）

```
[正常时]
KK wecom_bridge.py
  → HTTPS_PROXY=http://100.108.193.84:7897 (gt-air，注：CLAUDE.md 写的 amacbook-pro 是过时信息)
  → gt-air / 强二的 Clash 出去
  → 出口固定 IP = 182.96.37.119 ✅ 命中企微白名单

[故障时]
gt-air / amacbook-pro 上的 Clash 服务挂了（端口 7897 不响应）
  → wecom_bridge requests.post 抛 ProxyError
  → 自动 fallback 直连
  → 出口 = KK 家庭宽带 PPPoE 拨号 IP（动态、漂移）
  → 不在白名单 → 60020
```

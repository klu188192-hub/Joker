## EA 0-trade 检查清单（按发生频率）

1. **CSV 路径** — `FILE_COMMON` flag 时文件必须在 `Common\Files\`, 不在 `MQL5\Files\`
2. **CSV entry_time 时区** — broker server tz (一般 GMT+2/+3 EET), 不是 UTC
3. **FromDate < CSV first entry_time** — 否则 EA 加载但找不到 signal
4. **FindSignalForBar 容差** — `MathAbs(diff) <= 60`, 不能用 == 0
5. **Symbol 不存在 / broker 无数据** — 用 SymbolSelect() 检查
6. **CalcLot 返回 0** — sl_dist=0, tick_value=0, 算出 lot < broker min
7. **AtrZWindow=200 warm-up** — FromDate 必须留 200+ bar buffer
8. **MaxTotalExposurePct < BaseRiskPct** — cap 不够单笔进
9. **CSV direction 字段** — 严格 1/-1, 不能 BUY/SELL
10. **ExecutionMode/Visual 配置** — Visual=1 + ShutdownTerminal=0 会卡

**任何 0-trade backtest 都是 silent failure, 必须立刻报错。**

## 关键发现 / 决定

| 发现 | 含义 |
|---|---|
| 离线 HMM vs 在线 5-feature 分类器不一致 | Forward 部署必须用 Python HMM 实时服务 + CSV 推送，不能用 EA 内分类器 |
| Alpha 半衰期 ~6 月（85→15%）| 月度重训 HMM + 因子，部署带熔断 |
| Risk 1.5%→2.0% Calmar 反升 | 加杠杆是 free（直到心理 MDD 上限），但加 decay 会乘 |
| Python composite 比 MT5 真实 2× 高估 | 4 个独立复利曲线加总数学错误 |

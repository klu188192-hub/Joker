## 风控护栏 (TT 写死, DS 不能违反)

- 单笔风险 ≤ 1% ($10)
- 日亏 ≥ 3% ($30) → 强停整日
- 单仓 ≤ 4 笔
- 周五 20:00 服务器时间 → 全平
- DS API 5s 超时 → 默认 reject

## 第一版策略 (DS 自己设计)

- 标的: XAUUSD.s (M1 入场, M5 趋势确认)
- **入场**: 价格突破布林(20,2) + RSI(14) > 70 / < 30 + M5 MACD 同向 + 成交量 > 1.3x
- **SL**: 入场价 ± 0.2 USD (~20 points)
- **TP**: 入场价 ± 0.5 USD (~50 points, R/R 1:2.5)
- **仓位**: 固定 0.01 手
- **时段**: UTC 04-06 + 12-16

## 学习/进化机制

- 每天收盘后, daily_learn.py 读 SQLite 出统计
- 触发"重写 prompt"条件:
  - 连续 3 天净亏损
  - 单日亏损 > 3%
  - 周胜率 < 40% (软触发)
- 重写后, 失败案例摘要注入下日 prompt

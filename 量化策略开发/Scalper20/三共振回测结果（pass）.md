# TripleResonance 三指标共振 EA — 回测结果

## 设计目标
基于用户 spec：HMA(20) + STC(80,27,50) + UT Bot(2.0, ATR 6) **三重共振**才入场。
预期：稀有但高确信信号，剥头皮 R/R 1:1.5。

## 测试条件
- 标的: XAUUSD.s
- 周期: M5
- 期间: 2025.01-2026.04 (15 个月)
- 起始: $10,000, 杠杆 1:500
- SL/TP: 入场 K 高低点 ± 1pip / 比例 1.5
- 风险: 1%/笔

## 失败诊断

**核心问题**：1492 笔交易（3.6× 多于 Scalper20 A1+A3）说明三重共振**没有起到过滤作用**——HMA + STC + UTBot 在 M5 上各自都产生大量假信号，三个叠加后仍触发频繁。

**数学根因**：
- 平衡 WR = 1/(1+1.04) = 49.0%
- 实际 WR 47.79%，差 1.2pp → 期望 -$1.98/笔
- 1492 × -$1.98 = -$2,961 ✓ 与实测吻合

**与 Scalper20 v0.25 对比**：
- 同样的 R/R ~ 1.0-1.2 区间，同样的 ~48% 胜率
- TR 笔数 3.6× 多 → 同样负期望被放大 → 总亏损更大
- TR 平均亏损 -$82 vs v0.25 -$69 → 入场 K 高低 SL 距离比固定 $10 SL **更宽**

## 不投产决定

理由：
1. PF 0.95 < 1.0（数学不盈利）
2. DD 40% 接近爆仓
3. 同样信号哲学（剥头皮）下，Scalper20 v0.25（A1+A3 反转信号）已是更优解
4. TR 想救只能调参（更严信号阈值），但工期预估 3-5 天不值得

**保留代码作为参考**（位置 `D:\EBC-3\MQL5\Experts\TripleResonance.mq5`），不再迭代。

## 教训

1. **"三重共振"不等于"高质量"**——如果每个指标本身就有大量假信号，叠加后仍假
2. **M5 周期上 HMA/STC/UTBot 都太敏感**——这些指标更适合 H1+ 周期
3. **Scalper20 v0.25 的高 PF 来自 A1+A3 真正稀有 + 实盘画像验证**，不是简单的指标共振

## 后续替代方案

如果还想做指标共振 EA，建议：
- 改 H1 或 H4 周期（指标更稳）
- 减少到双指标 HMA + UTBot（删 STC，太敏感）
- 加入趋势过滤（H4 EMA200 方向）
- 但优先级低于 Scalper20 优化或新策略
